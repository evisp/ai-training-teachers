# Lesson planning

Prompts for planning lessons, units and learning objectives.

<div class="prompt-card" markdown>

### Create a lesson plan

<span class="tag tag--all">All levels</span>

**Use when:** you need a first draft of a lesson.

```text
Act as an experienced [subject] teacher for [grade] students.
Create a [45]-minute lesson plan on [topic].
Include learning objectives, a warm-up activity, the main activity,
a short check for understanding, and homework.
Present it as a table with timings.
```

!!! tip "Make it better"
    Add your curriculum objective and the misconceptions your students usually have.
